# PhyloMAT

A 2026 web rebuild of PhyloMAT, an automated protein motif analysis tool for phylogenomics. I designed the original in 2003 for my MS at the University of Illinois, and the programmers on the paper built it. This version is a work in progress, built with AI coding agents.

Original paper: Graham WV, Tcheng DK, Shirk AL, Attene Ramos M, Welge ME, Gaskins HR. PhyloMAT: an automated protein motif analysis tool for phylogenomics. J Proteome Res. 2004;3(6):1289. PMID: 15595740.
